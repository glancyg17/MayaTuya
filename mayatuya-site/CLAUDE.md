# Maya Tuya — site repo (read this first)

Static bilingual (EN/ES) site for **Maya Tuya**, a travel-tech and cultural brand on the Tren Maya route, founded by Glancy.
Plain HTML/CSS/JS generated by one Python script. No framework, no WordPress, no database.
Hosted on **Cloudflare Workers (static assets)**, deployed automatically from `main` by Workers Builds.

**The business has zero revenue. The first sale is the priority.** Glancy works alone: keep every change small, reviewable and executable by one person.

## How to work here

- **Edit `src/` and `config.json`. Never edit `docs/`** — it is generated and committed. After any change run `python build.py` and commit `src/` *and* `docs/` together.
- Preview locally: `python build.py --serve` → http://localhost:8000
- Check before finishing: `python build.py` (read the `note:`/`todo:` lines) and `python tools/qa_sweep.py` (needs `pip install playwright && playwright install chromium`).
- `python build.py --check-release` is **expected to fail** until launch items are done (see "Before going live"). Don't "fix" it by hacking the checks.
- Work on a branch and open a PR when the change is more than a typo; Workers Builds creates a preview URL per branch.

## Where things live

| Thing | Where |
|---|---|
| Site constants, nav, hosting/mode flags, Stripe + form keys | `config.json` |
| Every page: URL, title, description, EN↔ES pair, noindex | `src/pages.json` |
| Page bodies (hand-written HTML sections, each with its own `<style>`) | `src/content/<id>.html` |
| Footers | `src/partials/footer_en.html`, `footer_es.html` |
| Forms (`{{form:11}}` token in a page → rendered form) | `src/forms.json` |
| Shared CSS/JS (header, forms, native widgets) | `src/assets/css/site.css`, `src/assets/js/site.js` |
| Old WordPress URLs → new (301s) | `src/redirects.json` |
| Wrong links inherited from the old site → corrected | `src/link_fixes.json` |
| Images/PDFs the pages use (originals) | `media_src/` → build copies only referenced files to `docs/assets/` |
| Cloudflare config | `wrangler.jsonc` (assets dir = `docs`) |

The header, footer, language switch, canonical + hreflang, sitemap, robots, `_redirects`, `_headers` are all generated. Page ids are `<slug>-<lang>` (e.g. `exp-walls-en`).

## Rules that matter

1. **Bilingual pairs move together.** Every EN page has an ES counterpart (`pair` in `pages.json`). If you change one, change the other — and write natural Spanish/English, never literal translation. Spanish uses Mexican usage.
2. **Brand voice:** calm, restrained, observational, human. Never salesy. No exclamation marks, no urgency tricks, no "amazing/unforgettable".
3. **Design tokens (Codex §6):** dark green `#013220` (primary; theme palette also has `#0b3d2e`), gold `#c89e4b`, gold-dark `#9a7828`, cream `#f3eee2` (page background — *not* `#f2e9d0`), ink `#0c0b09`. Fonts: Playfair Display SC / Playfair Display (headings), Lato (body), Cormorant Garamond (italic accents). Don't introduce new fonts or colours.
4. **No frameworks, no build tooling beyond `build.py`.** Keep dependencies at zero (`lxml` is only for `tools/extract.py`).
5. **Links are root-relative** (`/assets/...`, `/inicio/...`) and internal URLs end with `/`.
6. **Don't change prices, capacity or availability claims** (price, min/max guests, times) without Glancy confirming — the Master Codex is the source of truth and a few live pages currently disagree with it (see Open items).
7. **Payments:** Stripe Payment Links only, referenced as `{{stripe:key}}` tokens resolved from `config.json`. Never invent a link. Never put secret keys in the repo (payment-link URLs and the Web3Forms access key are public by design).
8. **Forms** post to Web3Forms and are tagged by subject (`[MT booking]`, `[MT acuerdo]`, …) for Gmail filters. Don't rename field names without telling Glancy — those names appear in the notification emails.
9. **Paid PDFs** are protected only by obscure filenames and noindex pages. Don't link them from indexable pages or put them in the sitemap.

## Staging vs live

`config.json` → `"mode": "staging"` makes every page `noindex`, uses `new.mayatuya.com` for canonicals and blocks crawling. **Do not set `"mode": "live"` or touch DNS without Glancy's explicit go-ahead.**

## Before going live (open items)

- Replace `PLACEHOLDER_…` values in `config.json` (Web3Forms access key; Stripe links — the three existing live links are in `stripe_live_reference`).
- Put the 3 non-public PDFs in `media_src/` (names in README) and run `python tools/fetch_media.py` for the rest.
- Set `"mode": "live"`, attach `mayatuya.com` as the Worker's custom domain, make email/MX records are untouched.
- Styling uniformity pass across all pages (Glancy is collecting notes).
